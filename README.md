# Chapter — Alpha 0.2

Application web React/Vite de suivi de lecture.

## Fonctions

- Recherche de livres avec Open Library
- Couvertures réelles
- Ajout dans la bibliothèque
- Statuts À lire / En cours / Terminé
- Notes et avis
- Sauvegarde locale sur l'appareil
- Thème clair/sombre

## Netlify

Build command: `npm run build`
Publish directory: `dist`
